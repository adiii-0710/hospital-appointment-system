Hospital Appointment Booking System
A simple full-stack hospital appointment booking system built with React, Node.js, Express, and MongoDB.
Features
- Patient registration & JWT login
- Doctor listing and availability
- Secure appointment booking
- Slot conflict validation
- Patient appointment history
- Doctor appointment schedule
- RESTful API with MongoDB/Mongoose
Tech Stack
Frontend: React, Vite, CSS
Backend: Node.js, Express.js
Database: MongoDB, Mongoose
Authentication: JWT, bcrypt.js
Project Structure
backend/   → Express REST API
frontend/  → React frontend

Run Locally
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev

Built as a B.Tech CSE mini project demonstrating REST APIs, authentication, MongoDB relationships, and appointment management.
